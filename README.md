# Nexora Growth

[![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-black?style=for-the-badge&logo=vercel)](https://nexora-growth-website.vercel.app/)

> **Live Website:** [https://nexora-growth-website.vercel.app/](https://nexora-growth-website.vercel.app/)

Nexora Growth is a modern, responsive digital solutions and development agency website showcasing digital projects, web design, software development, AI solutions, and creative media services.

## 🚀 Features

- **Dynamic Hero Section**: Sleek modern layout with quick access to services and portfolio.
- **Projects Showcase & Modal**: Filterable digital solutions showcase with responsive media modals.
- **Interactive Team Carousel**: Smooth sliding showcase for core team members.
- **Process & Services**: Step-by-step workflow and comprehensive digital capability highlights.
- **Client Testimonials & FAQs**: Responsive reviews carousel and interactive accordion FAQs.
- **Contact Form & Direct Actions**: Easy consultation scheduling and direct inquiries.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup
- **Vanilla CSS**: Modern custom properties, responsive flexbox/grid layouts, animations
- **Vanilla JavaScript**: Filter logic, carousels, modal viewports, interactive elements

## 💻 Getting Started Locally

You can preview the website using any local web server or directly opening `index.html` in your browser.

Using PowerShell:
```powershell
.\server.ps1
```
Or with Python:
```bash
python -m http.server 8000
```
Or with Node (`npx serve`):
```bash
npx serve .
```
